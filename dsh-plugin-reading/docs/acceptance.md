# 阅读插件 · 人工验收清单

> 2026-11-09 首次验收通过（用户确认）：入口/书架、阅读器、书内目录页跳章、选段问 AI 流式回答、
> 存为笔记、书签、阅读进度恢复。以下清单保留为后续版本回归用。
>
> 前提：插件已在 desktop profile 启用（`dsh.profile.bundles` 含 `@local/dsh-reading`）。
> 客户端代码改动后需要**刷新页面（Ctrl+R）**才会加载新的 `client.js`（打包版没有 dev:web 热更）。
> 预检命令：`node scripts/preflight.mjs`，全绿再启用。

## 1. 入口

- [ ] 左侧栏出现「阅读」图标（order 30，在「插件」「自动化任务」之后）。
- [ ] 点击后主区域切换到阅读页，顶部标题「阅读」，两个 tab：书架 / 笔记。
- [ ] 再点其他侧栏项切走，再点回来，书架仍在（进度已保存）。

## 2. 书架

- [ ] 显示已导入的 4 本书：論語、論語集註、唐诗三百首、宋词鉴赏辞典；有封面的显示封面，无封面的显示文字封面。
- [ ] 排序切换（最近阅读 / 导入时间 / 书名）生效；搜索图标打开全文搜索浮层。
- [ ] 卡片悬浮出现「继续阅读 / 删除」；删除需二次确认。

## 3. 阅读器

- [ ] 打开《論語集註》：正文按源文件排版（繁体原字、段首缩进、朱注、引文、列表）。
- [ ] 顶部按钮：目录 / 书签 / 笔记 / 设置；左右箭头或 ←/→ 切章。
- [ ] 左侧抽屉目录：点任意章跳转，当前章高亮；点书签行回到对应位置。
- [ ] 「目录页」内链：打开《宋词鉴赏辞典》第 1 章（目录页），点击词牌/篇名能跳到对应章节。
- [ ] 设置：字号/行距/内容宽度/字体/主题改动即时生效，刷新后保持。
- [ ] 滚动到底部：上一章/下一章可点；整书进度条随阅读前进。
- [ ] 关闭页面再打开该书：回到上次章节与大致位置。

## 4. 选段与 AI 问答

- [ ] 在正文中选中一段文字，出现浮动工具条（问 AI / 记笔记 / 复制）。
- [ ] 右键选中文字同样出现（应阻止浏览器默认菜单）。
- [ ] 点「问 AI」：右侧抽屉打开，自动聚焦输入框；发送后答案流式出现。
- [ ] 快捷键：Ctrl/Cmd+Enter 发送；流式过程中可「停止」。
- [ ] 「存为笔记」后切到笔记页能看到该条（原文 + 问 + 答）。
- [ ] 「带入对话」：跳到新会话，输入框里是整理好的选段 + 问题草稿（未自动发送）。

## 5. 笔记

- [ ] 笔记页可按 全部 / 当前书 / 关键词筛选。
- [ ] 编辑（补记 / 回答 / 标签）、删除、跳转原文、导出 Markdown 都可用。
- [ ] 阅读器右侧笔记抽屉只显示当前书笔记。

## 6. Agent 协作

- [ ] 新对话里让 agent「列一下我的书架」，应调用 `reading_shelf` 并返回 4 本书。
- [ ] 让 agent「读一下论语集注学而第一并帮我整理三条笔记」，应调用 `reading_chapter` + `reading_notes`，笔记出现在笔记页。

## 已知限制

- 诗集类（《唐诗三百首》）无篇目标记，仍是 1 章长文。
- 书内目录页内链按标题匹配：同名篇目（如不同作者的同一词牌）会落到第一个同名章节；无法匹配的链接降级为普通文字。
- PDF 不在 v1 范围。
